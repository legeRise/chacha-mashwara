# Titles

## The title is the rule

Every video title is the rule itself. No subtitle, no "horror story," no clickbait
prefix. The viewer should be able to repeat the rule after reading it once.

**Good:**

- Never Answer the Door After Midnight
- Don't Take the Last Seat on the Bus
- Never Call Back a Number You Don't Know
- Don't Count the Guests at a Wedding
- If Someone Calls Your Name From the Roof, Don't Look Up

**Bad:**

- The Haunted House Story 😱
- You Won't Believe What Happened Next
- The Scariest Video on the Internet
- A Story About a Door
- Chacha Mashwara Episode 47

## Title rules

1. **Imperative.** Start with *Never, Don't, Always, If, or Before.*
2. **Specific.** Name the action, object, place, or time.
3. **Visual.** The viewer should be able to picture the thumbnail.
4. **One promise.** No double hooks.
5. **Aim for 8 words, max 10.** Shorts truncate; the rule must land.
6. **No spoilers.** The rule states the danger, never the twist.
7. **No repeated rule.** If the title is semantically the same as an earlier one,
   it is rejected — even if the wording differs.

## Title patterns

| Pattern | Example |
|---|---|
| Never + action + condition | Never Answer the Door After Midnight |
| Don't + action + place | Don't Look in the Mirror at 3 AM |
| If + trigger, don't + action | If the Bell Rings Twice, Don't Open |
| Always + action + before | Always Check the Back Seat Before You Drive |
| Never + action + with + person/object | Never Take a Photo of a Sleeping Person |
| Don't + action + on + day/time | Don't Sweep the Floor After Sunset |

## Title language

English titles, Urdu stories. This is the current working formula: English gives
the Shorts feed a wider reach; the story keeps the Pakistani voice. If analytics
show a strong Urdu-title advantage, test a volume with Urdu titles and log it.

## Thumbnail text

The thumbnail carries a 2–5 word fragment of the rule, not the whole title:

- **NEVER ANSWER**
- **DON'T LOOK**
- **LAST SEAT**
- **DON'T COUNT**

Chacha's corner mark and the rulebook icon stay constant. The text changes.

## Title review checklist

- [ ] Is it a rule someone could actually follow?
- [ ] Is it specific enough to picture?
- [ ] Does it promise a story, not a lecture?
- [ ] Is it different from every title in `rules/rules.csv`?
- [ ] Would a viewer understand the danger without watching?
