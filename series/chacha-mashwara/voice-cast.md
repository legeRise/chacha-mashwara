# Voice Cast

The story is performed by multiple actors. Chacha is the only voice in the frame;
he never performs a character inside the story. Every story role is cast from the
ensemble below.

## The rule

- **2–4 voices per episode.**
- **One actor = one character per episode.** No double-casting.
- **No narrator.** If a line explains the plot, it belongs to a character who wants
  something, or it is cut.
- **Ordinary voices, not "creepy narrator" voices.** The horror is in the situation,
  not in the performance.
- **Chacha is the anchor.** He speaks only in the cold open and the return.

## Core voice profiles

| Code | Role | Age | Texture | What they bring |
|---|---|---|---:|---|
| **CH** | Chacha Mashwara | 55–65 | Warm, low, measured, unhurried | Authority without threat; sadness under the warmth |
| **V1** | Young Man | 18–30 | Earnest, slightly proud, quick | The audience's "I would have done that" |
| **V2** | Young Woman | 18–30 | Watchful, practical, direct | Notices the wrong thing first |
| **V3** | Mother / Elder Woman | 40–60 | Warm, tired, sharp | The voice of experience that is ignored |
| **V4** | Father / Elder Man | 40–60 | Authoritative, soft underneath | The rule-keeper who bends |
| **V5** | Child | 7–12 | Direct, unadorned, unnerving | Says the true thing without knowing it |
| **V6** | Stranger / Worker | 30–50 | Polite, a little too calm | Driver, guard, shopkeeper, guest; sees everything |
| **V7** | Bride / Groom | 20–35 | Hopeful, distracted, pulled | The future being decided by others |
| **V8** | Neighbor / Relative | 30–55 | Nosy, helpful, carries the rumor | The community's memory |

## Casting patterns

| Story type | Typical cast |
|---|---|
| Domestic rule | V1 or V2 + V3 or V4 + V6 |
| Road / travel rule | V1/V2 + V6 + V8 |
| Wedding rule | V7 + V3 + V8 |
| Childhood rule | V5 + V2/V3 + V6 |
| Family rule | V3 + V4 + V1/V2 |
| Old object rule | V2 + V6 + V8 |
| Stranger rule | V1/V2 + V6 + V5 (optional) |

## Performance notes

- **Do not play the genre.** Play the want. The fear comes from the situation.
- **Overlap is allowed.** Real families interrupt. The editor can cut the overlap.
- **Silence is a line.** A breath before the lie is worth more than a scream.
- **No whisper-acting.** The threat is not a radio DJ. Speak clearly.
- **Urdu, everyday.** Chacha can be formal; everyone else speaks like a person.
- **No comedy.** The old lateefa voices are retired. Warmth is allowed; jokes are not.

## Chacha's voice

- Late fifties, low, close.
- Speaks as if the viewer is sitting across a table.
- A faint everyday lilt; not theatrical.
- Pauses before the rule and before the verdict.
- Never shouts. Never pleads. Never explains the supernatural.
- The verdict is a sigh, not a punchline.

## Casting the first 14 episodes

Use the same four actors for the first two weeks so the audience learns the
voices. Rotate the fifth and sixth actor in week three. Do not introduce a new
voice for every episode; the ensemble is part of the brand.
